# 🌐 Connectly - Social Media Platform

A full-stack social media platform developed as part of **CodeAlpha Task 2**. Connectly allows users to create profiles, share posts, interact through likes and comments, follow other users, and explore content through a simple and user-friendly interface.

## 🚀 Features

- 👤 User Profile
  - View profile information
  - Edit name and bio
  - Upload profile picture
  - Display posts, followers, and following counts

- 📝 Create Posts
  - Create text posts
  - Upload and share images
  - Display posts in the home feed

- ❤️ Like System
  - Like posts
  - Unlike posts
  - Display like counts
  - Likes are stored in the database

- 💬 Comment System
  - Add comments to posts
  - Display comments with posts
  - Comments are stored in the database

- 👥 Follow / Unfollow
  - Follow other users
  - Unfollow users
  - Track followers and following counts

- 🔎 Explore Page
  - Discover posts
  - View shared content
  - Explore posts separately from the home feed

- 🗑️ Delete Posts
  - Delete posts created by the user

- 💾 Database Integration
  - Users
  - Posts
  - Comments
  - Likes
  - Followers
  - Data persists after refreshing the page

- 🏠 Home Feed
  - View posts in one place
  - Interact with posts using likes and comments

## ⚙️ How to Run the Project
### 1. Open the Project

Download or open the project folder in **Visual Studio Code**.

### 2. Install Dependencies

Open the terminal in VS Code and run:
npm install

3. Start the Server
Run: node server.js
4. Open the Application
open your browser and visit:
http://localhost:3000
🌐 Application Features

🏠 Home
View posts and interact with them through likes and comments.
🔎 Explore
Discover and explore posts shared on the platform.
👤 Profile
View and edit profile information, including name, bio, and profile picture.
📝 Posts
Create text and image posts and display them in the feed.

Like and unlike posts with database-backed like counts.

Add and view comments on posts.
